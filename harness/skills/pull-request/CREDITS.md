# Credits

This skill is written for factory projects. It adapts ideas from two MIT-licensed skill libraries
and doesn't depend on either of them at runtime:

- [mattpocock/skills](https://github.com/mattpocock/skills), `skills/engineering/pr`: a small
  visual (file tree, call tree or shaped diff) in place of a prose summary, "tests are green" as a
  claim that needs evidence, and the one-way or two-way door. That skill credits its visuals menu
  to Dex Horthy's `show-me` skill ([humanlayer](https://github.com/humanlayer/humanlayer)). No
  text is copied here, only the ideas. Copyright (c) 2026 Matt Pocock.
- [garrytan/gstack](https://github.com/garrytan/gstack), `ship`: writing the body to a file and
  posting it with `--body-file` instead of a shell string, a fresh body on every run, never
  showing an unrun check as passed, and grouping commits by theme. Ideas only, no text copied.
  Copyright (c) 2026 Garry Tan.
