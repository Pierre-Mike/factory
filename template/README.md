# __APP_NAME__

Generated by `axioms new`. Runs on Cloudflare Workers (API + static web app) with D1.

```bash
bun install
bun run dev      # http://localhost:5173
bun run check    # every gate
bun run smoke    # the real worker, over HTTP
```

First deploy:

```bash
bunx wrangler login
cd apps/server && bunx wrangler d1 create __APP_NAME__   # paste the id into wrangler.jsonc
cd ../.. && bun run deploy
```

After that, `.github/workflows/deploy.yml` deploys every push to `main` (or, with
`"axioms": { "deploy": "manual" }` in package.json, only when you run `gh workflow run deploy`).
It needs two secrets on GitHub; `bunx axioms doctor` warns until both exist:

```bash
gh secret set CLOUDFLARE_API_TOKEN
gh secret set CLOUDFLARE_ACCOUNT_ID
```
